# 參考資料 {#reference-material}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]目前在Beta中。
>
>此處顯示的功能、工作流程和UI不一定代表產品的最終狀態。 若要加入Beta，請傳送電子郵件至llm-apps-beta@adobe.com。

本節提供[!DNL Adobe LLM Apps] UI中動作設定的欄位層級參考。

## 動作引數

輸入引數是LLM平台([!DNL ChatGPT]、Claude)傳送給動作處理常式的值。 模型會從使用者的訊息中擷取這些欄位，並自動將其對應至這些欄位。

| 屬性 | 說明 |
|----------|-------------|
| **名稱** | 引數識別碼（例如，`category`， `query`） |
| **類型** | `String`、`Number`、`Integer`或`Boolean` |
| **說明** | 人類看得懂的解釋 — LLM平台會使用這個來擷取正確的值 |
| **必要** | 如果勾選，模型必須在叫用動作之前提供此引數 |

### 檔案引數

檔案引數攜帶具有`download_url`和`file_id`屬性的檔案物件。 定義當使用者上傳交談中的檔案時應該接收檔案資料的輸入欄位名稱。

## 中繼資料欄位

### 基本資訊

| 欄位 | 必要 | 說明 |
|-------|----------|-------------|
| **動作名稱** | 是 | 動作的識別碼（例如，*搜尋產品*） |
| **說明** | 是 | 動作功能的說明 — LLM平台會使用此動作來決定何時叫用 |

### 註解

描述動作行為的可選提示：

| 註解 | 說明 |
|------------|-------------|
| **破壞性提示** | 動作會修改或刪除資料 |
| **等冪** | 使用相同的引數多次呼叫動作會有相同的結果 |
| **開放世界提示** | 動作會與外部系統互動 |
| **唯讀提示** | 動作只會讀取資料，不會寫入 |

### OpenAI中繼資料

| 欄位 | 最大長度 | 說明 |
|-------|------------|-------------|
| **正在叫用狀態文字** | 64個字元 | 動作執行時在LLM平台中顯示的訊息（例如，*正在載入產品……* ） |
| **叫用的狀態文字** | 64個字元 | 動作完成後顯示的訊息（例如，*載入的產品……* ） |

### 可見度

| 切換 | 說明 |
|--------|-------------|
| **公開給AI模型** | AI模型可在對話期間叫用該動作 |
| **在應用程式表面顯示為Widget** | 動作會在應用程式中呈現視覺化的Widget |

### Widget資訊

| 欄位 | 說明 |
|-------|-------------|
| **類型** | Widget技術 — 目前為&#x200B;**[!UICONTROL EDS]** |
| **Widget網域（沙箱來源）** | 代管Widget的來源；每個應用程式必須是唯一的 |
| **偏好框線** | 如果勾選，Widget會在LLM平台的框線卡中呈現 |

### 範本URL

| 欄位 | 說明 |
|-------|-------------|
| **[!UICONTROL 指令碼URL]** | 進入點指令碼 — `https://main--<repo>--<owner>.aem.live/scripts/aem-embed.js`。 在所有動作之間共用 |
| **Widget內嵌URL** | 此動作的EDS頁面 — `https://main--<repo>--<owner>.aem.live/eds-widgets/<action-name>`。 每個動作不重複 |

## CSP設定

內容安全性原則可控制Widget iframe可聯絡的外部網域。 每個外部網域都必須明確加入允許清單。

| 指示詞 | 說明 |
|-----------|-------------|
| **資源網域** | 靜態資產的網域 — 影像、字型、指令碼、樣式 |
| **連線網域** | Widget可以透過`fetch`、`XHR`或`WebSocket`聯絡的網域 |
| **框架網域** | 巢狀iframe允許來源；觸發更嚴格的應用程式檢閱 |
| **重新導向網域** | `openExternal`個重新導向連結的受信任目標（[!DNL ChatGPT]個特定） |
| **基礎URI網域** | `base-uri` CSP指示詞（僅限MCP Apps SDK，而非[!DNL ChatGPT]） |

## 權限

允許Widget存取的硬體和瀏覽器API。 這些對應至iframe許可權原則。

| 權限 | 說明 |
|------------|-------------|
| **攝影機** | 存取裝置攝影機 |
| **麥克風** | 存取裝置麥克風 |
| **地理位置** | 存取使用者的位置 |
| **剪貼簿** | 讀取或寫入剪貼簿 |
