# 動作和Widget欄位 {#action-widget-configuration}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]目前在Beta中。
>
>此處顯示的功能、工作流程和UI不一定代表產品的最終狀態。 若要加入Beta，請傳送電子郵件至llm-apps-beta@adobe.com。

使用此頁面來查閱動作編輯器中的欄位。 如需建立步驟，請參閱[從頭開始建立動作](/help/guides/create-action.md)。

## 尋找設定

**[!UICONTROL 建立新動作]**&#x200B;對話方塊有&#x200B;**[!UICONTROL 動作]**&#x200B;和&#x200B;**[!UICONTROL Widget中繼資料]**&#x200B;標籤。

建立之後，儲存的動作編輯器會使用三個索引標籤：

| 標籤 | 設定 |
|---|---|
| **[!UICONTROL LLM Widget詳細資料]** | Widget型別、沙箱網域、Widget說明、範本URL和CSP |
| **[!UICONTROL 動作詳細資料]** | 程式碼識別碼、說明、輸入引數和&#x200B;**[!UICONTROL LLM設定]**，包括註解、引動狀態文字和可見度 |
| **[!UICONTROL 分析]** | 使用者意圖收集和指示 |

若要儲存您的編輯，請選取&#x200B;**[!UICONTROL 儲存變更]**。 正在等待檢閱的產生動作改為顯示&#x200B;**[!UICONTROL 標籤為已檢閱]**，這也會處理其產生的提取要求。

## 動作引數

輸入引數是LLM平台傳送給動作處理常式的值。 模型會從使用者的訊息中擷取值，並將這些值對應至設定的引數。

| 屬性 | 說明 |
|----------|-------------|
| **名稱** | 引數識別碼（例如，`category`， `query`） |
| **類型** | `String`、`Number`、`Integer`或`Boolean` |
| **說明** | 人類看得懂的說明 — LLM平台會使用該說明來擷取正確的值 |
| **必要** | 如果勾選，模型必須在叫用動作之前提供此引數 |

### 檔案引數

檔案引數是在動作編輯器中設定的輸入欄位名稱。 當使用者上傳檔案時，主機會為這些引數提供檔案物件，通常包括`download_url`和`file_id`。

## 中繼資料欄位

### 基本資訊

| 欄位 | 必要 | 說明 |
|-------|----------|-------------|
| **動作名稱** | 是 | 動作的顯示名稱（例如，*搜尋產品*） |
| **說明** | 是 | 動作功能的說明 — LLM平台會使用說明來決定何時叫用動作 |

建立對話方塊會預覽從動作名稱衍生的不可變&#x200B;**程式碼識別碼**。 這是應用程式內獨一無二的，最多可包含63個字元（以小寫字母開始），並使用小寫字母、數字、連字型大小或底線。 它將動作對應到處理常式存放庫中的`actions/<code-identifier>/index.js`。

### 註解

描述動作行為的可選提示：

| 註解 | 說明 |
|------------|-------------|
| **破壞性提示** | 此動作可能會刪除或覆寫資料 |
| **等冪（相同的引數=沒有額外效果）** | 重複相同的請求對環境沒有額外的影響；重複請求不一定會傳回相同的資料 |
| **開放世界提示** | 動作會與外部系統互動 |
| **唯讀提示** | 動作只會讀取資料，不會寫入 |

### OpenAI中繼資料

| 欄位 | 最大長度 | 說明 |
|-------|------------|-------------|
| **正在叫用狀態文字** | 64個字元 | 動作執行時在LLM平台中顯示的訊息（例如，*正在載入產品……*） |
| **叫用的狀態文字** | 64個字元 | 動作完成後顯示的訊息（例如，*載入的產品……*） |
| **Widget說明** | 512個字元 | 對應至`_meta["openai/widgetDescription"]`；彙總模型的演算元件，並減少重複的旁白 |

動作說明可控制模型何時選取動作。 Widget說明說明會說明元件在呈現之後顯示的內容。

### 可見度

若要開啟或關閉動作，請在應用程式頁面上使用其&#x200B;**[!UICONTROL 可見度]**&#x200B;開關。 切換器會控制下一個部署是否包含動作。 動作編輯器沒有單獨的開啟/關閉開關。

以下動作編輯器設定可控制模型和Widget曝光，而非應用程式層級的開啟/關閉狀態：

| 切換 | 說明 |
|--------|-------------|
| **公開給AI模型** | AI模型可在對話期間叫用該動作 |
| **在應用程式表面顯示為Widget** | 動作會在應用程式中呈現視覺化的Widget |

模型和Widget曝光度設定不會取代選擇Widget型別。

### 分析

| 欄位 | 說明 |
|-------|-------------|
| **收集使用者意圖** | 預設為啟用。 要求導致分析動作的目標匿名摘要 |
| **使用者意向描述** | 用於要求摘要的指示，最多2,000個字元。 預設會排除個人和敏感資訊。 檢閱針對您的隱私權原則的任何自訂 |

## Widget欄位

### Widget資訊

| 欄位 | 說明 |
|-------|-------------|
| **型別/Widget型別** | 在建立對話方塊中，選取&#x200B;**[!UICONTROL Edge Delivery Services區塊]**&#x200B;或&#x200B;**[!UICONTROL 無Widget]**。 儲存的編輯器會加上純文字選擇&#x200B;**[!UICONTROL 無互動式UI]** |
| **Widget網域** | 主機使用的沙箱來源。 UI會根據應用程式提交和每個應用程式唯一性的要求識別它。 這與EDS頁面的&#x200B;**Widget URL**&#x200B;不同 |
| **偏好框線** | 要求邊界容器；轉譯須視主機而定。 可在建立對話方塊中使用 |

### 範本URL

| 欄位 | 說明 |
|-------|-------------|
| **[!UICONTROL 指令碼URL]** | EDS `scripts/aem-embed.js`進入點的HTTPS URL。 在同一EDS專案中的跨動作共用 |
| **Widget URL** | 動作轉譯之EDS頁面的HTTPS URL。 產生的動作會自動設定URL |

## CSP設定

內容安全性原則可控制Widget iframe可聯絡的外部網域。 每個外部網域都必須明確加入允許清單。

| 指示詞 | 說明 |
|-----------|-------------|
| **資源網域** | 靜態資產的網域 — 影像、字型、指令碼、樣式 |
| **連線網域** | Widget可以透過`fetch`、`XHR`或`WebSocket`聯絡的網域 |
| **框架網域** | 巢狀iframe允許來源；觸發更嚴格的應用程式檢閱 |
| **重新導向網域** | `openExternal`個重新導向連結的受信任目標（[!DNL ChatGPT]個特定） |
| **基礎URI網域** | `base-uri` CSP指示詞（僅限MCP Apps SDK，而非[!DNL ChatGPT]） |

## 權限

Widget許可權控管對硬體和瀏覽器API的存取。 許可權對應至iframe許可權原則。

許可權控制項出現在建立對話方塊的&#x200B;**[!UICONTROL 許可權（MCP特定）]**&#x200B;下。 僅授予Widget所需的功能；主機支援和使用者同意也適用。

| 權限 | 說明 |
|------------|-------------|
| **攝影機** | 存取裝置攝影機 |
| **麥克風** | 存取裝置麥克風 |
| **地理位置** | 存取使用者的位置 |
| **剪貼簿** | 讀取或寫入剪貼簿 |
