# 生產熒幕擷圖程式

您可以使用此程式從下列來源擷取真實的公開檔案熒幕擷取畫面：

`https://experience.adobe.com/#/@llmapps/llm-apps/`

首選的工作流程是人工擷取，然後是代理程式協助擷取。 使用者會決定哪些生產狀態相關；該技能會整理、清理並將它們整合到檔案中。

## 擷取收件匣

將每個擷取執行放在：

```text
docs-captures/<YYYY-MM-DD>/
```

Git會忽略目錄。 原始熒幕擷取畫面必須保留在本機，絕不可認可。

使用者可以使用任何檔案名稱，但排序的名稱可讓檢閱更容易：

```text
01-create-app.png
02-connect-github.png
03-onboarding-enabled.png
04-generating-actions.png
05-review-actions.png
```

選用的`capture-notes.md`可描述遺失狀態、異常行為或預期的順序。

## 安全界限

- 使用者直接在瀏覽器中輸入Adobe、GitHub和LLM平台憑證。
- 停止取得MFA、密碼金鑰、驗證碼、組織選擇和特殊許可權同意。
- 絕對不要讀取、列印、儲存或認可Token、Cookie、瀏覽器儲存空間或認證。
- 使用不敏感的公共網站和全新的僅說明檔案存放庫。
- 僅授予GitHub應用程式對夾具使用的兩個存放庫的存取權。
- 建立、部署、刪除、封存或變更存放庫存取權前先詢問。
- 請勿擷取個人資訊、組織ID、存放庫安裝ID、權杖或完整執行階段URL。

## 夾具命名

使用可清楚識別可棄用檔案資源的名稱：

```text
App: LLM Apps Docs <YYYY-MM-DD>
Handler repo: llm-apps-docs-<YYYYMMDD>
EDS repo: llm-apps-docs-<YYYYMMDD>-eds
```

建立任何專案之前，請先向使用者確認目標Adobe組織、GitHub擁有者、公用網站和夾具名稱。

建立空白和私用的存放庫。 請勿使用README、授權或`.gitignore`初始化它們。

## 擷取設定

- 請使用足夠大的案頭檢視區，以在沒有瀏覽器鉻色的情況下顯示完整的對話方塊。
- 將縮放比例保持在100%。
- 除非文章特別教授主題，否則請使用預設產品主題。
- 擷取包含任務和必要前後關聯的最小完整區域。
- 避免游標、開啟與步驟無關的功能表、來自先前動作的快顯通知以及暫時性旋轉器（除非旋轉器是記錄狀態）。
- 使用PNG。
- 保持檔案名稱穩定；在重新整理期間取代影像內容而非重新命名檔案。

## 建議的擷取順序

使用者應從資訊清單中擷取相關狀態，包括：

1. 在GitHub連線之前建立應用程式。
2. GitHub應用程式存放庫存取權選取專案。
3. **自動建立我的應用程式**，並選取兩個存放庫。
4. 應用程式建立或入門代理程式啟動。
5. 正在產生動作。
6. 產生的動作已準備好審查。
7. 一個代表動作的中繼資料、處理常式和Widget。
8. 每個動作檢閱和所有動作檢閱的狀態。
9. 成功的中繼部署。
10. LLM平台中的應用程式註冊與代表結果。

當其他畫面說明實際決策、錯誤或先決條件時，擷取這些畫面。 不要擷取每次點按。

## 技能輸入工作流程

當使用者要求從擷取資料夾更新檔案時：

1. 確認確切的擷取目錄。
2. 清查所有PNG、JPEG和WebP檔案，並視覺化檢查每個影像。
3. 建立從來源檔案到`screenshot-manifest.md`中專案的對應。
4. 將可見的UI標籤和順序與現有教學課程進行比較。
5. 報告：
   - 缺少必要狀態；
   - 複製或多餘的影像；
   - 順序模稜兩可；
   - 過時的熒幕擷取畫面；
   - 敏感資訊；
   - 與檔案衝突的生產行為。
6. 請勿編輯來源擷取。
7. 針對每個接受的影像，在`help/assets/guide-onboarding-agent/`下建立具穩定資訊清單檔案名稱的已清理復本。
8. 只有在周圍的UI沒有新增任何有用的內容時，才能裁切。
9. 遮罩敏感值。 如果無法進行安全遮罩，請要求重新擷取。
10. 更新文章和替代文字以符合擷取的工作流程。
11. 執行連結和資產驗證。
12. 在使用者明確要求移除擷取資料夾之前，請將其保留在原處。

## 選擇性代理程式引導式擷取

如果使用者要求代理程式驅動瀏覽器，請使用相同的資訊清單和安全界限。 暫停驗證、授權同意、存放庫變更、應用程式建立、部署和清除。 絕對不要在無人看管的情況下執行此生產變異流程。

## 影像檢閱

對於每個影像：

- 將其與一個資訊清單專案比對。
- 驗證文章中的UI副本。
- 裁切掉不需要的帳戶導覽。
- 遮罩個人名稱、頭像、組織識別碼、儲存庫安裝識別碼、執行階段名稱空間以及不相關的應用程式。
- 確認看不到瀏覽器自動填寫、電子郵件、存取Token或私人存放庫詳細資料。
- 撰寫同時識別熒幕和狀態的替代文字。

## 何時停止

出現下列情況時停止並報告封鎖程式：

- 生產不符合記錄的工作流程。
- 稽核流程和已發佈的檔案有很大不同。
- 存放庫驗證會拒絕預期的空白存放庫流程。
- 入門管道失敗。
- 有特殊許可權的動作需要使用者或管理員。
- 若未隱藏步驟的必要資訊，熒幕擷圖就無法變成安全狀態。
