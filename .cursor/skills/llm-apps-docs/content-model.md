# 內容模式與術語

## 內容型別

### 教學課程

教導新使用者完成一個完整的成功歷程。

- 說明結果和先決條件。
- 使用一個範例應用程式和一個序列。
- 僅說明每個步驟所需的概念。
- 以工作結果結束，並清除後續步驟。

主要教學課程： `help/guides/create-app.md`。

### 概念

說明零件如何關聯，而不成為程式或欄位目錄。

- 專注於心智模式與所有權界限。
- 使用小圖表可增進瞭解。
- 教學課程、操作指南和參考資料的連結。

### 操作指南

協助有見識的使用者完成一項工作。

- 從所需的結果開始。
- 僅包含工作特定的先決條件。
- 偏好使用建議的路徑。
- 完整欄位參考的連結。

範例：從頭開始建立動作、自訂Widget、引進EDS專案、部署和測試。

### 參照

提供使用者在工作時查詢的事實資訊。

- 依產品或程式碼表面組織。
- 精確地定義每個欄位、合約、命令、限制和狀態。
- 避免教學課程敘述和重複的範例。

### 疑難排解

從可觀察的症狀開始。

- 說明可能的原因。
- 提供安全的診斷步驟。
- 避免要求使用者透露認證或敏感記錄。

## 標準術語

- **Adobe LLM應用程式** — 第一次提及時的完整產品名稱。
- **LLM應用程式** — 由產品管理的單一應用程式。
- **上線代理程式** — 建立初始支架的功能。
- **建置我的應用程式** — 建立應用程式對話方塊中的UI區段。
- **自動建置我的應用程式** — 確切的核取方塊標籤。
- **動作** — 功能公開至LLM平台。
- **動作中繼資料** — LLM應用程式儲存的名稱、說明、結構描述、註解、可見度和Widget設定。
- **動作處理常式** — 處理常式存放庫中的伺服器端函式。
- **處理常式存放庫** — 包含處理常式與測試的存放庫。 只有在描述該控制項時，才使用UI標籤&#x200B;**樣板存放庫**。
- **EDS存放庫** — 包含Widget區塊和內容的存放庫。
- **Widget** — 在LLM平台中呈現的視覺回應。
- **MCP伺服器URL** — 已部署端點向LLM平台註冊。
- **ChatGPT外掛程式** — 從MCP伺服器URL建立的ChatGPT整合。
- **暫存**&#x200B;和&#x200B;**生產** — 部署環境。

除非說明MCP通訊協定詳細資訊，否則請避免在面對使用者的散文中的「工具」和「動作」之間切換。

## 推薦的讀者歷程

1. 概述和先決條件。
2. 使用入門代理程式建立應用程式。
3. 檢閱產生的動作。
4. 部署至中繼並測試ChatGPT外掛程式。
5. 自訂產生的處理常式和Widget。
6. 將自訂應用程式部署到生產環境。

從頭開始建立動作並帶來EDS專案是進階分支，而不是預設的首次執行歷程。
